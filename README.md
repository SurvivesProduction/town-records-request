# town-records-request

A free, copy-and-paste email template for requesting a town's assessor property data (CAMA export) under the Connecticut Freedom of Information Act.

Towns already keep this data in their assessor software. Asking for the export is usually faster than scraping the town's lookup website, and the file is cleaner.

## How to use it

1. Open [`request-email.md`](request-email.md).
2. Copy the email text and fill in the bracketed parts: your name, your phone number and the email address the file should go to.
3. Send it to your town's assessor. If the town has no assessor email, send it to the town clerk.
4. Reply to the fee quote if one comes back.

## Why it is worded this way

- **It names the export.** If the town uses Vision, "Warren Group extract (residential, commercial, condo)" is the name of an export that Vision already provides, so staff do not have to design a report.
- **It says "your standard export is fine."** This removes the work from the request. Staff can send what they normally produce.
- **It asks for the fee first.** A fee quote before fulfillment keeps you from being billed for something you did not agree to. It also shows the request is made in good faith.

## Notes

- This is a template, not legal advice. Check the current text of the Connecticut FOIA and your town's process.
- Property records can include owner names and mailing addresses. Handle the data you receive responsibly and follow the law that applies to how you use it.
